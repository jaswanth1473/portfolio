Tender Management System

Web3Blockchain Architecture

Project Overview

I built this Tender Management System because I wanted to see if I could completely eliminate fraud and bias from the standard bidding process. It's a fully decentralized application where every single interaction—like creating a tender or picking the winner—gets recorded permanently on the blockchain so no one can mess with it.

Architecture & Implementation

Building this required a really interesting bridge between standard web tools and a decentralized Ethereum backend.

  • Smart Contracts (Solidity): Instead of a normal server, all the core rules live directly on Ethereum. Things like checking if a bidder is eligible or opening sealed bids happen totally on autopilot.
  • Frontend Integration: I knew people wouldn't want to dig into code to bid, so I built a really clean React dashboard. Web3.js handles all the complex MetaMask wallet connections invisibly behind the scenes.
  • Decentralized Storage: Huge blueprint files are hashed and tossed into IPFS so they can never be quietly altered or deleted by a bad actor.
  • Node.js Middleware: A Node layer sits in the middle to link normal user accounts (OAuth) to their actual Web3 wallet signatures.

Impact & Outcomes

By enforcing an encrypted, decentralized workflow, the system fundamentally solves the "trust" issue in tender assignments. It guarantees that bids cannot be viewed early and that the rules of selection execute without any human intervention.
